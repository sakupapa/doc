# 導入編（Getting Started）

このドキュメントでは、プロジェクトをローカル環境で立ち上げて、開発を始めるための基本手順を説明します。

## 前提条件

作業を始める前に、以下のツールがインストールされていることを確認してください。

* **Node.js**: v18 以上の LTS バージョン
* **npm**: v9 以上

## ステップ 1: リポジトリのクローン

まずはリポジトリをローカルマシンにクローンし、プロジェクトディレクトリに移動します。

```bash
git clone https://github.com
cd your-project
```

## ステップ 2: 依存関係のインストール

プロジェクトに必要なパッケージをインストールします。

```bash
npm install
```

## ステップ 3: 開発サーバーの起動

インストールが完了したら、開発用サーバーを起動します。

```bash
npm run dev
```

起動に成功すると、ターミナルに以下のようなURLが表示されます。ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスしてください。

!!! success "チェックポイント"
    ブラウザに「Welcome to Our App」と表示されていれば、ローカル環境の構築は完了です！
